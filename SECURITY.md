# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.
Use GitHub's private vulnerability reporting for this repository
(Security tab, "Report a vulnerability").

Include the affected component, steps to reproduce and the impact you see.
You will get an acknowledgement as soon as the report is read.

## Scope

The repository is public and contains no secrets, personal data or premium
content. If you find any of these in the history, report it the same way.
